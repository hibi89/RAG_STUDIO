02-A / UNAPPROVED LOCAL CSV

CSV 구조·자료형 검토

읽기 전용 · 데이터 반입 없음

내 PC에서 선택한 CSV 1개를 이 로컬 프로그램(127.0.0.1)에서만 검사합니다. 후보 자료형·행 오류·검토 항목만 표시하며 원본 저장, 자동 승인, SQLite 반입, 기존 지표 변경은 하지 않습니다.

모든 필드는 NEEDS_REVIEW · SMAX 승인 아님

파일을 선택하고 검사하면 헤더·후보 자료형·오류 위치가 표시됩니다.

02 / LOCAL SOURCE CHECK

SMAX 매출 미리보기

원본 대조 · 승인되지 않은 분석

SMAX 전처리 결과 JSON과 같은 작업에서 사용한 원본 CSV를 선택하세요. 브라우저는 이 로컬 프로그램(127.0.0.1)으로만 파일을 보내며, 파일은 저장하거나 기존 대시보드의 검증된 데이터에 병합하지 않습니다.

자동 승인 없음 · 고객 데이터 반입 인증 아님

두 파일을 선택하면 로컬 미리보기 결과가 표시됩니다.

02 / GROUNDED INTELLIGENCE

근거 기반 질의

근거가 확인된 단일 반품/배송 기간 질문 후 “그건 며칠이야?”라고 후속 질문할 수 있습니다. 대화 기록은 저장하지 않습니다.

질문을 입력하면 검증된 계산 결과와 문서 출처가 표시됩니다.

원본 행이나 문서 출처를 선택하면 검증된 위치와 내용을 확인할 수 있습니다.
