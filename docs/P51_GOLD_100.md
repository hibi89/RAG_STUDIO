# P5.1 — 100-item synthetic golden-question evaluation (2026-10-27 KST)

## Scope and design decision

The `RAG_P5_GOLD_V0` corpus is now **exactly 100 synthetic questions**, including the unchanged P5.0 seed 24 and 76 new manually curated questions. Questions were authored against the public synthetic fixture and its known contract; they were **not independently validated by real users, customers or external evaluators**.

| Alternative | Speed | Quality, maintenance, cost | Decision |
|---|---|---|---|
| A. Add 76 positive paraphrases only | Faster to make pass | Inflates scores with easy duplicates, misses partial-answer bugs | Rejected |
| B. Add positive paraphrases, unsupported filters, fees, related-domain requests and mixed near-misses with exact expected status/evidence | Modest extra engineering | Improves precision boundary and regression detection at zero paid API cost | Selected |

### Coverage breakdown

| Expected output | Cases | Nature |
|---|---:|---|
| Fixed SQLite-only metrics | 12 | Revenue/order/unit synonyms |
| Citation-only document periods | 29 | Return/refund 7 days and shipping preparation 2 business days, plus combinations |
| SQLite and document citations | 17 | Mixed supported questions, exact 6 orders / 10 units / 157000 KRW |
| Complete abstention (`NOT_SUPPORTED`) | 42 | Fees, item-level/group/time aggregations, stock, cancellation, exchange, shipping tracking/ETA, unsupported mixed intents |
| **TOTAL** | **100** | One publicly checked-in synthetic manifest/CSV/TXT fixture |

All 100 are **distinct exact question strings and case IDs**. The fixture is **not real data**. The gold corpus does not yet exercise conflicting/insufficient data scenarios as individual evaluation cases, although pre-existing regression tests exercise those conditions. Cases are not paraphrase-independence-certified; synthetic gold pass rate must never be marketed as real retrieval accuracy.

## Changes

- `fixtures/p5_gold_v0.json`: 76 new questions with fixed expected status, source IDs, type and date/quantity evidence expectations; preserves earlier 24.
- `src/evidence-router.mjs`: explicitly rejects unsupported scoped sales dates, item/customer groupings, averages, forecasts, stock, cancellations, exchanges, refund payouts, delivery tracking and unsupported mixed requests. No fabricated partial metric or policy answer. No additional API/SQL commands or private data import.
- `tests/p5-gold-eval.test.mjs`: update exact count from 24 to 100, strict unique ID/question check and 12/29/17/42 coverage, 12 directly checked near-miss abstentions and retained positive mixed citations. No new dependencies or changes to production server/UI.
- `src/gold-eval.mjs` and runner unchanged; `npm run test:gold` uses built-in read-only Node scripts, never network/paid inference in product execution.
- Explicit no-autonomous-external-data movement, no human approval or SMAX Private source modification. Old ref `develop` before feature = `80601bf94a3bababfed2e1f98f70b4fd7e2cbfc7`.

## Remaining gaps and boundaries

- The current result is 100/100 on an authored synthetic corpus from a single known dataset. Full release requires independently reviewed/held-out real-world questions and any customer data handling separately approved.
- Existing protected dashboard, browser evidence flow, private SMAX producer, trusted human authorization, Windows 3-machine installer, original RAG ZIP, PDF/DOCX, BM25+dense extensions, license/customer terms and production Vercel are not newly verified/completed by this feature.
- Only forward merge to `develop` after verifying tested code SHA differs from HEAD by documentation only, using normal non-force fast-forward; leave `main` unchanged.
