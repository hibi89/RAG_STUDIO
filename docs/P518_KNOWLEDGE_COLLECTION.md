# P5.18 — Selected local Knowledge Base and evidence comparison

Date: 2026-10-27 KST; public `RAG_STUDIO`, synthetic developer preview.

## Runnable experience
Run `npm ci --ignore-scripts --no-audit --no-fund` and `npm run demo:zip`, open the private local URL. In **문서와 출처**, check **지식베이스 포함** on 1–8 SHA-verified TXT/Markdown sources. In **선택 문서 지식베이스**, enter e.g. `반품 신청 기간` and press **선택 문서 검색**. Results and citations come only from selected sources; global `문서만 검색` remains unchanged. Choose 2+ sources and press **선택 문서 정책 대조** to render explicit return/shipping preparation policy fragments side-by-side, with each original document/title/file ID/line/quote. Periods are classified calendar_days vs business_days, never blindly ranked across units.

## Safety/contract
`POST /api/knowledge` requires `{action:'search',project_key,document_ids,question}` or `{action:'compare',project_key,document_ids}`; project_key is the opaque current local project key from `GET /api/projects`, not a path. Strict 1–8 unique current-manifest accepted documents, UTF-8 TXT/MD only; no user paths, no arbitrary SQL, no generated answer, no PDF raw extraction, no external network/file writes. Maximum 4KiB HTTP JSON body and 500-char question, plus all-source line limits. Session bearer authentication, POST Origin, Host, project mismatch 409 and package SHA rechecks per request. Unknown IDs, unapproved, unsupported, tampered and invalid requests fail closed. User selection is per-page memory only, and changed scope/project clears old results; in-flight old requests are discarded.

`search` supplies BM25 source fragments but is **not a semantic policy answer**. `compare` inspects all selected lines using narrow explicit Korean return-application and shipping-preparation-start patterns. If distinct document IDs with recognized policy assertions are fewer than two, `INSUFFICIENT_EVIDENCE`, no answer. If different period values exist for the same policy domain, `POSSIBLE_CONFLICT`, no definitive answer and all matching review citations. With two distinct documents and no recognized disagreement, `COMPARISON_READY` displays raw claim matrix. Complex policy conditions, versions, effective dates, different cohorts/regions, implicit units and legal validity are **not supported**. A status of ready is not a certified policy interpretation.
