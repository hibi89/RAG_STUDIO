# P1: SQL + TXT Document First Vertical Slice

> 2026-10-26 KST. Synthetic-only, no customer data, no APIs or deployment. Product-ready RAG/SMAX/SOVIA integration is **not** claimed.

## Design choice

| Design | Speed/cost | Limitations | Decision |
|---|---|---|---|
| A. Node.js 22.16+ built-in `node:sqlite`, in-memory | No pip/npm dependencies; fixed prepared statements; portable one-runtime packaging candidate | **Experimental API** in Node 22; Windows/packaging unverified | **P1 selected** |
| B. Python stdlib `sqlite3` companion process | Mature standard library, reliable SQL aggregation | Two runtimes and IPC/installer burden | Reserve if Node SQLite packaging fails |

The P0 manifest SHA-256 and approval checks are mandatory before import. Source CSV/TXT are never modified. Only verified `dataset-sales` is imported into memory; the import uses a fixed prepared statement. Database is then switched to `PRAGMA query_only = ON`; end-user question strings are never compiled or interpolated into SQL. Only bounded safe integers are accepted. Document policy line is found in the verified TXT with a concrete source line, not generated by an LLM.

## Usage

Node.js **>=22.16.0** required for the P1 demo. Node.js 22's `node:sqlite` may show `ExperimentalWarning`.

```bash
npm test
npm run demo:mixed
node src/mixed-cli.mjs fixtures/ax_sample_v0 '총 매출과 반품 규정을 알려줘'
```

Expected status `ANSWERED`; SQL totals: orders `6`, units `10`, revenue `157000` KRW. TXT citation: `file-policy`, line `2`, the 7-day returns line. Synthetic data are not real contract terms. Unknown question intent yields `NOT_SUPPORTED`, missing approved policy text yields `INSUFFICIENT_EVIDENCE`. CLI returns exit code `2` for unsupported/insufficient answers and `1` for invalid or tampered input.

## Evidence and boundaries

- Local container Node.js 22.16.0: P0 `16/16` regression PASS; P1 `12/12` PASS; total `28 PASS / 0 FAIL / 0 SKIP`. `npm run demo:mixed` produced an exact source-linked answer; SQLite mutation after `query_only` was rejected in a test. These are **local** tests, not GitHub Actions or Windows tests.
- P1 is **not general SQL chat**, not SQL generation, not semantic document RAG, not PDF/FAISS/BM25, not persistent SQLite, not SMAX real producer integration, not Windows self-installer, not SOVIA. Domain is a single validated synthetic CSV + TXT pair.
- Early safety: bound file sizes, schema/approval, hashes, traversal/symlink rejection (from P0); unsupported arithmetic beyond exact range rejected. Broader ZIP, normalization, path race conditions, LLM prompt injection, multidoc relevance tests belong to subsequent production gates.
